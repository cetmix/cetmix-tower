This module safely wraps the Python ``tldextract`` library for use in
Cetmix Tower commands. It exposes the ``extract()`` method through a
shared evaluation context.

Use Cases / Context
===================

Wrapping ``tldextract`` as a separate module prevents loading
unnecessary dependencies in unrelated environments. It enables domain
parsing without requiring OVH integration.

Usage
=====

Cetmix Tower TLDExtract Usage
=============================

This module provides the Python ``tldextract`` library (wrapped safely)
for use in Python commands in Cetmix Tower.

Example
-------

.. code:: python

   # Extract domain parts
   result = tldextract.extract("sub.example.co.uk")
   domain = result.domain  # example
   suffix = result.suffix  # co.uk
