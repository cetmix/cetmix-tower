Cetmix Tower Git GitHub

List branches, open pull requests, and commits from github.com on the Head field of a Git remote.

Click Head to open the first page, or type to narrow that page. The value you pick is stored on the remote.

Configuration

Go to Cetmix Tower > Settings > General Settings > Cetmix Tower > GitHub.

Root can see that section. When it is missing, open Settings > Users & Companies > Users and set the user’s Cetmix Tower access to Root.

Set GitHub API Secret and save.

On the repository, set Secret when that repository has its own token. When Secret is empty, Tower uses the Secret on the repository owner. When both are empty, Tower uses GitHub API Secret from General Settings.

Tower resolves a secret in that order for Head autocomplete and for reading the GitHub repository id. Head autocomplete still uses server and partner values when they are known. Reading the GitHub id uses only a global value of the chosen secret; server-specific or partner-specific values are not used for that read.

Be careful about the scope of the token. Any token that can read the repository is enough.

Usage

From a Git project

Go to Cetmix Tower > Tools > Git Projects. Open a project.

On Sources, click Add a line and open the source.

On Remotes, click Add a line.

Set Head Type to Branch, Pull/Merge Request, or Commit. Click Head and choose a row.

From a Jet

Go to Cetmix Tower > Jets > Jets. Open a Jet.

On Git Project, click Add a line. Set Head Type, then click Head and choose a row.

What is stored

A branch name that contains /, such as feat/2233, is stored whole. A pasted https:// link keeps its last path segment.

A pull request row shows the number and the title, such as 510 [18.0][ADD] cetmix_tower_git_github: add module. Head stores 510.

A commit row in the list shows the first 7 characters of the SHA and the subject, such as 6e427eb [IMP] cetmix_tower_git: autocomplete git heads. Head stores the full SHA.

When no secret resolves, an error is shown and the list is empty. A typed value can still be saved.

Bug Tracker

Bugs are tracked on GitHub Issues. In case of trouble, please check there if your issue has already been reported. If you spotted it first, help us to smash it by providing a detailed and welcomed feedback.

Do not contact contributors directly about support or help with technical issues.
