Capture a Jet's Git Project with its backup: grouped sources, enabled
flags, repository URLs and privacy, heads, protocols, ordering,
aggregator root directory and notes. Restore creates an independent
project before the Restore plan starts, without changing the source
project. It also works after the source project is deleted.

A destination Jet Template must have Use Git Projects enabled. Sources
with no remotes are skipped. Source references are generated for the new
records, so aggregator source directories can differ from the original
Jet's directories.
