Adds strict isolation mode for Jets. When active, it prevents
non-privileged users from changing applicability or tags when running
commands or flight plans. This ensures that operations on sensitive jets
follow predefined security policies.

Usage
=====

1. Navigate to a **Jet Template**.
2. Enable the **Isolation Mode** checkbox.
3. Select the **Forced Applicability** (e.g., 'Only this server').
4. Optionally, select **Forced Command Tags** and **Forced Flight Plan
   Tags**.
5. Save the template.

When a user runs a command or plan on a jet using this template, the
specified values will be enforced and the fields will be read-only in
the wizard.
