To use this module, you need to:

1. Go to **Cetmix Tower** > **Servers**.
2. In the server **Kanban** view, open the manage menu on a server card and click **Terminal**.
   Alternatively, open a server form and click the **Terminal** button in the header.
3. An interactive SSH terminal session opens in a new browser tab or action pane.
4. Type commands and interact with the remote server in real time.
5. Click **Disconnect** or close the tab to end the session.
