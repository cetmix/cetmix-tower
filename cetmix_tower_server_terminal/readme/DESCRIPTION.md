This module adds an interactive SSH terminal to [Cetmix Tower](https://tower.cetmix.com)
servers. A manager opens a shell on a server from its form view and works in it in the
browser, with the SSH credentials, host key and access rules Tower already stores for
that server. No SSH client, no credentials on the technician's machine.

The terminal runs on [xterm.js](https://xtermjs.org), so colours, cursor keys, window
size and full screen programs such as `top`, `htop` or `vim` behave as they do in a
local terminal.

Please refer to the [official documentation](https://tower.cetmix.com) for detailed
information.
