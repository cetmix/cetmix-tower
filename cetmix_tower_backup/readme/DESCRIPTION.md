Keep durable Jet backup records, capture the Jet's own variable values, restore
into a new Jet, and remove stored backup data through configurable flight plans.
Tower stores metadata; the plans create, transfer, restore and delete the bytes.

Backups can be started from a Jet, a scheduled task, a Create Backup command,
or a waypoint backed by a Backup Template. Optional Git integration captures
sources and remotes and creates an independent Git Project when restoring.
